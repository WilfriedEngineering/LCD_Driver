# LCD_Driver
Character LCD driver for Microchip PIC16F87XA microcontrollers using MPLAB XC8.  The driver is designed to interface with character LCD modules based on the LM016L, LM020L, and LM041L displays.

## Status

The driver source code and demonstration files are available in this repository.

Detailed documentation will be added progressively.

## Supported LCD Modules

* **LM016L** — 16 × 2 character Digits
* **LM020L** — 16 × 1 character Digits
* **LM041L** — 16 × 4 character Digits

## Contents

* LCD Driver source files
* Demo application
* Proteus simulation
* Compiled HEX firmware
* Test schematic
* Test demonstration video

## Target Platform

* **MCU:** Microchip PIC16F87XA Family
* **Compiler:** MPLAB XC8
* **Interface:** Parallel character LCD
* **LCD Modules:** LM016L, LM020L, and LM041L
